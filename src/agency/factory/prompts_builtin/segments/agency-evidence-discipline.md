# Evidence Discipline

Every material claim must be grounded in observable evidence.

- Cite the artifact that proves each claim: file, function, address, command output, or test result.
- Keep three buckets explicit: CONFIRMED (observed), INFERRED (reasoned from evidence), UNKNOWN (not yet demonstrated).
- Prefer deterministic checks over judgment when a check exists.
- When evidence conflicts or is missing, say so and define the smallest experiment that would resolve it.
