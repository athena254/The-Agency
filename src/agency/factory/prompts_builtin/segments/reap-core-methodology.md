# REA Investigation Methodology

Derived from the REAP prompt-writing tips (REA Investigation Prompts, MIT).

1. **One feature per request.** Narrow questions return call chains and addresses; broad questions return shallow maps.
2. **Demand evidence.** Every conclusion cites a file, function, or address.
3. **Separate fact / inference / unknown.** Use the three-bucket format for all findings.
4. **Static first.** Do not execute the target until runtime observation is actually required.
5. **End with a deliverable.** A spec, reader script, port plan, or minimal rebuild forces verification.
6. **State the scope out loud.** Name the authorization boundary for the work.
