# Archive

Historical records: session handoffs, research notes, qualification and review
dispositions, dated status checkpoints, and the evidence files they cite
(`research-evidence/`, `completion-briefs/`). Also the original holdout scenario
list ([HOLDOUT_SCENARIOS.md](HOLDOUT_SCENARIOS.md)).

These documents are kept for provenance. They describe what was believed or
verified at a past revision, and they go stale. For the current state of the
system, read [../CURRENT_STATE.md](../CURRENT_STATE.md); where anything here
disagrees with it, CURRENT_STATE.md wins.
