## Current canonical checkpoint (local only)

This local checkpoint includes the disk-backed budget foundation through `e614c79`, default-deny Agency/Butler HTTP boundaries through `af7b7f4`, dormant opt-in local tools through `7d95c42`, and unauthoritative peer-message signing primitives through `d3d6ef5`; the running bot remains a separate older checkout, **not** this revision. See [SPEC_BETA_BOUNDARY_AND_PEER_EXECUTION.md](SPEC_BETA_BOUNDARY_AND_PEER_EXECUTION.md), [SPEC_KNOWN_PEER_PROTOCOL.md](SPEC_KNOWN_PEER_PROTOCOL.md), and [SPEC_BETA_HTTP_CUTOVER.md](SPEC_BETA_HTTP_CUTOVER.md) for security contracts and the undecided peer failure model. No push, beta deployment or bot restart follows from these local commits.

- **B-04 / B-14:** `a503037` enforces strict private-chat boolean and denies omitted search count when it could exceed a tighter cap; the earlier explicit policy-factory fix was already on consolidated main. These are unit/tool-boundary fixes, **not** trusted Telegram→Butler→local execution wiring. No beta tool surface is approved yet.
- **B-05:** `d73553b` + `9296a3e` move fetch DNS preflight off the event loop, bound unresolved DNS worker capacity and redact resolver errors. Independent review passed the revised change; full isolated-branch suite reported **910 passed**. Connection is still not pinned to validated DNS, so **`web_fetch` remains disabled for beta**.
- **B-07:** `51797ef`, `dd8e97c`, `e614c79` integrate an isolated disk-backed request/model quota **foundation** with same-process reservation capabilities, fail-closed replay/restart and close-race behavior, and transactional pruning. The correction passed independent bounded review; its last isolated full suite reported **938 passed**, with Ruff, format and mypy passing. **It is not wired into Telegram ingress, Butler or live provider dispatch; no production budget is enforced.** Cancellation after durable reservation can leave a fail-closed unauthorizable duplicate (availability tradeoff). Select and prove reset/limit semantics and end-to-end owner-bound model calls before beta.

- **B-13:** an experimental beta-only registry audit gate exists only on `fix/beta-audit-gate` (`462e748`). Independent review **blocked** it: a no-op append can report success, the builtin audit default is in-memory/NORMAL, beta refusal evidence and tool exception text can leak input, and a TypeError retry can duplicate an append. It is unmerged and unwired. Audit failure handling in the actual end-to-end beta path remains open.
- **B-17:** `34309e0` specifies independently running known peers, per-peer stores, affected-consumer input and no global orchestrator authority. **Peer execution is not implemented.** Fault class/quorum, membership and human-attestation proof remain undecided; consequential actions remain disabled. `d375102` maps the HTTP bypasses. `b10036d` and `af7b7f4` now deny all Agency/legacy Butler HTTP requests except GET health, including independently mounted Agency routers; reviewed for this narrow local cutover and tested on isolated branches. This is a temporary closed gate, **not** an implemented peer grant verifier, Telegram protection or proof that downstream actuators require a grant. An isolated, independently reviewed cryptographic envelope primitive was integrated as `b72923c` and `d3d6ef5` (the corrected branch suite reported **952 passed**); it signs/verifies bounded canonical peer messages but has **no authenticated transport, pinned membership, durable replay, quorum, grant or actuator connection**. It is not a decentralized runtime.
- **Extra tools:** `cd2afd4` specified opt-in nonbeta calculator and UTC-time tools; `fc15891` and `7d95c42` add them as dormant, explicit opt-ins without adding them to the legacy-open `register_all`. Independent review passed this limited merge after the beta helper was changed to construct a fresh strict search-only registry. **Production beta does not call that helper or bind a trusted principal; the new tools are not enabled in beta.**
- **B-11 / B-09:** source consolidation did not overwrite `data/lattice.db` or its SQLite sidecars. The local canonical working tree still shows runtime database changes and an untracked probe file; preserve them. No live deployment evidence is implied by these local test results.
